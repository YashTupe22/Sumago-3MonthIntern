## About

This repository contains all the code written during my 3-month internship at Sumago Infotech. ## Mini Projects

### ATM System
A simple ATM simulation with deposit, withdrawal, and balance check — first implemented with conditionals (Day 9), then refactored with loops (Day 10).

### Car Dealership System
A car rental system where users can browse Audi, BMW, and Mercedes Benz models, view pricing, and generate rental bills.

### Croma Billing System
An electronic store billing system — customers can browse products, select items, and generate bills.

### Bank Account System
Demonstrates OOP concepts with class-based bank accounts, deposit/withdraw functions, and decorator-based logging.

### Exploratory Data Analysis (EDA)
Real-world data analysis on an Amazon India sales dataset using pandas, numpy, matplotlib, and seaborn — covering data inspection, summary statistics, and visualization.
